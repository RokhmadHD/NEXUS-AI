# Research Plan

## Questions

1. Does recurrent latent-state processing improve state tracking?
2. Does symbolic supervision improve structured prediction?
3. Does consistency training improve paraphrase robustness?
4. What are the compute and latency trade-offs?

## Baselines

- Transformer only
- Transformer + GRU
- Transformer + symbolic branch
- Full NEXUS-AI

## Metrics

- Language modeling loss and perplexity
- State prediction error
- Symbolic precision, recall and F1
- Generalization to unseen combinations
- Latency, throughput and memory usage

## Reproducibility

Record seeds, configs, dataset versions, checkpoints and metrics.
